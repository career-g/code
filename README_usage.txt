【何が変わったか】
 1) 昨年の表と名前が同じ行は、その組をそのまま確定（名前が変わっていたら使わない）
 2) 昨年の表から「ベネの学科→河合の学科」を決め、一般入試の行も同じ学科の中だけで方式を比べる
 3) 私大・短大の方式は、学習した点数で学科内を全体最適に1対1で結ぶ（国公立は従来どおり）
    確実なもの＝印なし／自信が低いもの＝「推定」／数字・英字が食い違う＝「要確認」

【精度】
  今年（2027入試用）の河合ベネ表で採点:
   ・表にある行（共通テスト利用・国公立）: 99.99%一致、誤結合0
   ・参考: 昨年の表だけで作った仕組みを今年の正解で採点 → 旧mix 91.5% → 98.0%（初めて見る年度での実力）
   ・見たことのない大学での方式の的中率（私大・短大）: 約96%
  一般入試の行は正解表がないため数値では測れません（私大の約94%は学科を表から確定できます）。
  自信が低い対応は「推定」、数字・英字が食い違うものは「要確認」と表示されます。
